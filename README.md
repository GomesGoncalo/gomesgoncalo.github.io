# gomesgoncalo.github.io

Personal website, blog, and CV. Built with plain HTML/CSS/JS and deployed to GitHub Pages.

## Structure

```
index.html              # Portfolio / CV (single page)
blog/
  index.html            # Blog listing
  post.html             # Post reader (loads Markdown at runtime)
  posts.json            # Slug list generated by build.py
  posts/
    *.md                # Blog posts (Markdown with YAML frontmatter)
shared.css              # Design tokens, nav, layout — shared across all pages
shared.js               # Theme toggle, nav burger
build.py                # Generates posts.json and rss.xml
rss.xml                 # Generated — do not edit by hand
404.html                # Custom error page
```

## Writing a post

Create a Markdown file in `blog/posts/` with frontmatter:

```markdown
---
title: My Post Title
date: 2026-01-15
description: One-line summary shown in the post list.
tags: [tag1, tag2]
---

Post body here…
```

The slug is the filename without `.md`. `build.py` picks up all `.md` files automatically.

## Building locally

```bash
python3 build.py        # regenerates posts.json and rss.xml
```

Then open `index.html` or `blog/index.html` in a browser (or serve with any static server).

## Deployment

Pushing to `main` triggers the GitHub Actions workflow (`.github/workflows/deploy.yml`), which runs `build.py` and publishes the site to GitHub Pages.
